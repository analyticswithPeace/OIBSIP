# OIBSIP Task 1 – Retail Sales Exploratory Data Analysis

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset. The analysis was carried out to understand the structure of the data, identify important patterns and trends, and generate meaningful insights from the available retail information.

## Objective
The main objective of this task was to explore and analyze the retail sales data using Python-based data analysis and visualization techniques.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

### 1. Data Exploration
The dataset was inspected to understand its structure, variables, data types, and general characteristics.

### 2. Descriptive Analysis
Descriptive statistics were used to summarize the dataset and understand key numerical patterns and distributions.

### 3. Time Series Analysis
Sales data was analyzed over time to identify trends, changes, and patterns in sales performance.

### 4. Customer Demographic Analysis
Customer characteristics and demographic information were explored to understand the composition and behavior of the customer base.

### 5. Product Analysis
Product-level performance was analyzed to identify products with higher and lower sales and understand overall product trends.

### 6. Data Visualization
Charts and visualizations were created using Matplotlib and Seaborn to communicate important findings clearly.

## Key Insights
The analysis provided insights into:
- Sales trends over time
- Product performance
- Customer demographics
- Overall sales patterns
- Relationships and patterns within the retail dataset

## Conclusion
This project demonstrates the application of Exploratory Data Analysis techniques to transform raw retail sales data into meaningful insights. It also strengthened practical skills in Python, Pandas, NumPy, and data visualization using Matplotlib and Seaborn.
