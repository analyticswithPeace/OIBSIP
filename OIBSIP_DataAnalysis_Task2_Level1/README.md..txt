# OIBSIP Level 1 – Task 2: Customer Segmentation Analysis

## Project Overview
This project focuses on customer segmentation analysis for an e-commerce company. The objective is to segment customers into distinct groups based on their purchasing behavior, enabling the development of more targeted and effective marketing strategies.

## Objective
To apply clustering techniques to identify meaningful customer segments based on purchasing behavior and provide actionable insights for targeted marketing.

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

### 1. Descriptive Analysis
Explored the dataset to understand customer purchasing behavior and key characteristics.

### 2. Feature Selection
Selected relevant features for customer segmentation, focusing on purchasing behavior.

### 3. RFM Analysis
Analyzed key customer metrics including:
- Recency – how recently a customer made a purchase
- Frequency – how often a customer made purchases
- Monetary – how much a customer spent

### 4. Data Normalization
Normalized the selected features to ensure that differences in scale did not negatively affect the clustering algorithm.

### 5. K-Means Clustering
Applied the K-Means clustering algorithm to group customers with similar purchasing behaviors.

### 6. Cluster Visualization
Visualized the resulting customer clusters using Matplotlib and Seaborn.

### 7. Cluster Profiling
Examined the characteristics of each customer segment to understand their purchasing behavior.

### 8. Business Insights and Recommendations
Identified actionable insights from the customer segments and considered how the findings could support targeted marketing strategies.

## Key Outcome
The analysis identified distinct customer groups based on purchasing behavior, providing useful insights that can help an e-commerce business develop personalized marketing strategies and improve customer engagement.

## Conclusion
This project demonstrates the application of customer segmentation and K-Means clustering using Python. The analysis provides a data-driven approach to understanding customer behavior and supporting targeted business decisions.
