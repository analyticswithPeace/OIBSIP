# Google Play Store Analysis

## Overview

This project explores the Google Play Store to uncover trends and insights across app categories, ratings, installations, pricing, and user sentiment.

## Objectives

- Analyze app distribution across categories
- Explore app ratings and average ratings by category
- Examine the relationship between app size and installations
- Compare free and paid apps
- Analyze pricing and estimated revenue
- Explore user review sentiment
- Identify sentiment patterns across app categories

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook
- VADER Sentiment Analysis

## Datasets

- `Google_Play_Apps.csv` – Google Play Store app information
- `Google_Play_Reviews.csv` – User reviews and sentiment data

## Key Insights

The analysis provides insights into market saturation, app ratings, installation trends, pricing strategies, and user sentiment, helping developers better understand the Google Play Store market.

## Conclusion

The findings can help app developers identify competitive categories, understand user preferences, and make more informed decisions about app development, pricing, and market positioning.
